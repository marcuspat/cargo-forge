What it does

CLI, API server, WASM, game engine, embedded, library, workspace — scaffolded with real structure, not hello-world.

Interactive or scripted

Answer prompts in the terminal, or pass flags in CI — same output either way.

cargo install cargo-forge

One line, then `cargo forge new` and you are compiling.
